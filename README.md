# Музей акварельного наблюдения

Самостоятельная открытая гостевая 3D-экспозиция из безопасного пользовательского архива. Сайт построен как последовательная экскурсия, а не как один демонстрационный экран.

## Что добавлено

Экскурсия начинается со стартового экрана и ведёт через шесть залов: «Наблюдение», «Воздух», «Вода», «Конструкция», «Архитектура» и «Композиция». Есть карта маршрута, нижний прогресс, кнопки «назад» и «далее», финальный экран и повторный вход в любой зал.

Внутри сцены можно осматривать пространство перетаскиванием мыши или свайпом. На desktop работают стрелки клавиатуры и колесо мыши. Каждая картина открывается отдельной развёрткой с крупным изображением, наблюдением, развиваемым навыком и учебным заданием. Отдельный каталог показывает все 12 работ в одном месте.

Три выбранных безопасных фотографии переработаны в оригинальные акварельные композиции с усиленным центром внимания, светом, глубиной и иерархией деталей. Остальные безопасные WebP используются как учебные исходники. Документы, банковские карты и изображения с лицами в публичную версию не включены.

Сайт использует общие паттерны виртуальных музейных туров и каталогов, но не копирует бренд, тексты, изображения или исходный код Samokat, Gallerix или других сторонних проектов.

## Запуск на Ubuntu 20.04

```bash
sudo apt update
sudo apt install -y git python3
git clone https://github.com/mosaicin/museum-drawing-archive.git
cd museum-drawing-archive
python3 -m http.server 8080
```

Откройте `http://127.0.0.1:8080`. Для остановки сервера нажмите `Ctrl+C`.

## Файлы

`index.html` содержит экраны экскурсии, `style.css` — адаптивную визуальную систему и CSS-3D сцену, `app.js` — карту, шесть залов, управление, каталог и модальные развёртки, `assets/` — 15 локальных изображений.
