# Музей учебного рисунка

Самостоятельный открытый виртуальный музей, собранный по общим паттернам интерактивной музейной экспозиции: входной экран, виртуальные залы, карточки экспонатов, подробный просмотр и сброс экспозиции.

Сайт не копирует бренд, логотип, тексты, изображения, исходный код или фирменную айдентику сторонних проектов. Внутри используются собственные тексты, учебные задания и безопасные пользовательские WebP-изображения.

## Разделы

В «Зале наблюдения» изучаются силуэт, ритм, тон и фактура. В «Зале конструкции» — оси, перспективные эллипсы, плоскости и архитектурные массы. В «Зале композиции» — центр внимания, планы, пустота и скорость принятия решения.

## Запуск на Ubuntu 20.04

```bash
sudo apt update
sudo apt install -y git python3
git clone https://github.com/mosaicin/museum-drawing-archive.git
cd museum-drawing-archive
python3 -m http.server 8080
```

Откройте `http://127.0.0.1:8080`. Для остановки сервера нажмите `Ctrl+C`.

## Файлы

`index.html` содержит музейную структуру, `style.css` — визуальную систему и адаптивность, `app.js` — залы, модальные карточки и входной экран, `assets/` — локальные WebP-экспонаты.

Публичная версия не содержит документы, паспортные страницы, банковские карты и изображения с лицами.
