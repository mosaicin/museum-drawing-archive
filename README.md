# Музей акварельного наблюдения

Самостоятельная открытая 3D-галерея из безопасного пользовательского фотоархива. Фотографии здесь не оставлены в исходном виде: три выбранных сюжета переработаны в оригинальные акварельные композиции с усиленным центром внимания, иерархией деталей, светом и глубиной.

## Что можно посмотреть

Входной экран открывает музейный маршрут. В разделе «3D-тур» можно перетаскивать виртуальный зал мышью или пальцем, нажимать на картины и менять три цветовых состояния пространства. Колесо мыши также поворачивает зал. В каталоге каждая работа раскрывается как учебный разбор: главное, второстепенное, развиваемый навык и конкретное задание.

Структура вдохновлена общими паттернами виртуальных музейных туров и больших онлайн-каталогов: отдельные залы, поиск визуальных связей, карточки экспонатов и образовательные пояснения. Сайт не копирует бренд, логотип, код, тексты или изображения Samokat, Gallerix или другого стороннего проекта.

## Запуск на Ubuntu 20.04

```bash
sudo apt update
sudo apt install -y git python3
git clone https://github.com/mosaicin/museum-drawing-archive.git
cd museum-drawing-archive
python3 -m http.server 8080
```

Откройте `http://127.0.0.1:8080`. Для остановки сервера нажмите `Ctrl+C`.

## Файлы

`index.html` содержит музейную структуру, `style.css` — адаптивную визуальную систему и CSS-3D сцену, `app.js` — управление залом и карточки разбора, `assets/` — локальные WebP и три новые акварельные PNG-переработки.

Публичная версия не содержит документы, паспортные страницы, банковские карты и изображения с лицами.
