# Музей акварельного наблюдения

## Публичный адрес

Открытый исходный код и файлы: `https://github.com/mosaicin/museum-drawing-archive`.

Подтверждённый бесплатный preview: `https://cdn.jsdelivr.net/gh/mosaicin/museum-drawing-archive@main/index.html`.

Адрес `https://mosaicin.github.io/museum-drawing-archive/` пока не активен: GitHub Pages требует ручного включения владельцем репозитория. Для постоянного адреса откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку `main`, папку `/(root)` и нажмите **Save**. После публикации Pages адресом будет `https://mosaicin.github.io/museum-drawing-archive/`.

Полноценная открытая 3D-прогулка по безопасному пользовательскому фотоархиву. Это уже не витрина с наклонёнными карточками, а последовательный маршрут через десять музейных залов.

## Как устроена прогулка

Посетитель начинает во входной галерее и движется вперёд по залам. В каждом помещении есть стены, пол, перспективная глубина, арка в следующую часть маршрута и экспонаты справа и слева. В экспозиции используются 100 безопасных WebP из публичного пользовательского архива. Документы, банковские карты и лица в коллекцию не включены.

Движение работает кнопками «Вперёд» и «Назад», стрелками клавиатуры, свайпом/перетаскиванием для осмотра и колесом мыши для приближения к следующему залу. Нажатие на картину открывает отдельную развёртку с крупным изображением, наблюдением, навыком и учебным заданием. Карта залов и каталог доступны из верхней навигации.

Десять залов посвящены наблюдению, ритму, планам, тону, конструкции, органике, архитектуре, городу, фактуре и финальному переходу к практике.

Сайт использует самостоятельную реализацию CSS-3D сцены и не копирует код, изображения, тексты или бренд Samokat/Gallerix. Gallerix использовался только как ориентир для идеи большого каталога; чужие произведения туда не загружались.

## Запуск на Ubuntu 20.04

```bash
sudo apt update
sudo apt install -y git python3
git clone https://github.com/mosaicin/museum-drawing-archive.git
cd museum-drawing-archive
python3 -m http.server 8080
```

Откройте `http://127.0.0.1:8080`. Для остановки сервера нажмите `Ctrl+C`.

## Состав

`index.html` содержит гостевой маршрут, `style.css` — стены, пол, арки, перспективу и адаптивные элементы управления, `app.js` — камеру, переходы, 10 залов, 100 экспонатов, каталог и развёртки, `assets/collection/` — 100 безопасных изображений.
